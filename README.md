## 💼 Proyectos destacados

### 📱 Conóceme 
> *Proyecto propio | Arquitectura Mobile & Fintech en Tiempo Real*

Ecosistema móvil multi-rol (Explorador con gamificación, Comercio con validación QR y Administrador) integrado con motor GIS y una pasarela de pagos autónoma 24/7.

- **Pasarela Autónoma (Kotlin Nativo):** Procesamiento de pagos Yape/Plin en tiempo real mediante protocolo Ping-Pong (`< 2s`) y generación de QR dinámico bajo estándar EMVCo
- **Integridad Financiera:** Conciliación atómica ACID (`runTransaction`) en Firestore con protección anti-doble gasto
- **Motor Geoespacial (GIS):** Mapas interactivos y descubrimiento local impulsado por OpenStreetMap
- `Flutter` `Dart` `Kotlin` `Firestore` `GIS / OpenStreetMap` `EMVCo` `ACID`

---

### ⚽ [PichangaSaaS](https://pichangasaas.com) — Plataforma SaaS para Gestión Deportiva
> *Proyecto propio | En producción 🟢*

Plataforma **multi-tenant** para la administración integral de centros deportivos. Cada cliente opera con su propia base de datos aislada, garantizando privacidad y escalabilidad independiente.

- **Arquitectura Multi-tenant:** Base de datos por cliente para máximo aislamiento de datos
- **Backend:** API REST con Spring Boot, contenerizado con Docker
- **Frontend:** SPA en Angular con interfaz responsiva para reservas en tiempo real
- **Funcionalidades:** Gestión de canchas, reservas online, control de pagos y administración de horarios
- 🌐 **[pichangasaas.com](https://pichangasaas.com)**
- `Spring Boot` `Angular` `TypeScript` `PostgreSQL` `Docker` `Multi-tenant` `SaaS`

### 📚 Repositorio Institucional & Sistema de Biblioteca — Posgrado UNCP

Modernización del acceso al repositorio institucional y desarrollo de un sistema integral para el control y gestión de inventario bibliográfico de la Escuela de Posgrado de la UNCP.

### 🍔 Sistema de Gestión de Restaurante — Full Stack Cloud
> *Freelance | Dic 2025 – Ene 2026*

Sistema completo para gestión de menús, control de stock y autenticación segura con arquitectura de servicios independientes.

- **Backend:** API REST con Spring Boot desplegada en Render, con procedimientos almacenados complejos (`PL/pgSQL`)
- **Frontend:** SPA en Angular desplegada en Vercel, optimizada para velocidad y responsividad
- **Base de datos:** PostgreSQL en Supabase con triggers para garantizar integridad de datos
- `Angular` `TypeScript` `Spring Boot` `PostgreSQL` `Supabase` `Render` `Vercel`
