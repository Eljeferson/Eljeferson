## 💼 Proyectos destacados

### ⚽ [PichangaSaaS](https://pichangasaas.com) — Plataforma SaaS para Gestión Deportiva
> *Proyecto propio | En producción 🟢*

Plataforma **multi-tenant** para la administración integral de centros deportivos. Cada cliente opera con su propia base de datos aislada, garantizando privacidad y escalabilidad independiente.

- **Arquitectura Multi-tenant:** base de datos por cliente para máximo aislamiento de datos
- **Backend:** API REST con Spring Boot, contenerizado con Docker
- **Frontend:** SPA en Angular con interfaz responsiva para reservas en tiempo real
- **Funcionalidades:** gestión de canchas, reservas online, control de pagos y administración de horarios
- 🌐 **[pichangasaas.com](https://pichangasaas.com)**
- `Spring Boot` `Angular` `TypeScript` `PostgreSQL` `Docker` `Multi-tenant` `SaaS`
